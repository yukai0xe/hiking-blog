> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a "糧食清單" feature — a food items list per expedition post — with full-stack support: DB, C# backend, TypeScript store, two new Vue components, and new step 6 in Create/Edit flows.

**Architecture:** Foods are stored in a dedicated `foods` table (direct FK to `posts`, no library/mapping table like gears). The backend follows the existing layered pattern: `FoodModel` → `PostRepository` → `PostService` → `PostsController` using a new `FoodInputDto`. Frontend follows the GearQuickPick/GearList component pattern exactly.

**Tech Stack:** PostgreSQL (Supabase), C# .NET 9 / Dapper / Npgsql, Vue 3 + TypeScript + Pinia

## Task 3: PostRepository — Food Methods

**Files:**
- Modify: `D:\RiderProject\hiking-backend\hiking.Repository\Repositories\PostRepository.cs`

- [ ] **Step 1: Add three food methods at the end of `PostRepository`, before the closing `}`**

`PostRepository` only uses repository-layer models (never Service DTOs — that's the PostService's job). All three methods take `List<FoodModel>` where `PostId` and `Id` are already set by the caller.

```csharp
public async Task<List<FoodModel>> GetFoodsAsync(Guid postId)
{
    await using var conn = await db.OpenConnectionAsync();
    return (await conn.QueryAsync<FoodModel>("""
        SELECT id, post_id, name, weight, quantity, note, reference_url, price
        FROM foods
        WHERE post_id = @postId
        ORDER BY created_at
        """, new { postId })).ToList();
}

public async Task InsertFoodsAsync(List<FoodModel> foods)
{
    if (foods.Count == 0) return;
    await using var conn = await db.OpenConnectionAsync();
    await conn.ExecuteAsync("""
        INSERT INTO foods (id, post_id, name, weight, quantity, note, reference_url, price)
        VALUES (@Id, @PostId, @Name, @Weight, @Quantity, @Note, @ReferenceUrl, @Price)
        """, foods);
}

public async Task ReplaceFoodsAsync(Guid postId, List<FoodModel> foods)
{
    await using var conn = await db.OpenConnectionAsync();
    await conn.ExecuteAsync("DELETE FROM foods WHERE post_id = @postId", new { postId });
    if (foods.Count == 0) return;
    await conn.ExecuteAsync("""
        INSERT INTO foods (id, post_id, name, weight, quantity, note, reference_url, price)
        VALUES (@Id, @PostId, @Name, @Weight, @Quantity, @Note, @ReferenceUrl, @Price)
        """, foods);
}
```

Note: `ReplaceFoodsAsync` is used by `UpdateAsync` — it deletes all existing foods for the post and re-inserts. This is simpler than a full diff (YAGNI) and correct because the Edit.vue step always has the full intended list at save time.
